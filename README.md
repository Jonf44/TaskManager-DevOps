# TaskManager-DevOps

Sistema web para la gestión de tareas.

## Historias de usuario

### Historia de usuario 1: Registrar tareas

Como usuario del sistema, quiero registrar nuevas tareas para organizar mis actividades.

Criterios de aceptación:
- El sistema debe permitir ingresar el nombre de la tarea.
- El sistema debe permitir agregar una descripción.
- El sistema debe permitir seleccionar una prioridad.
- El sistema debe guardar la tarea.
- El sistema debe mostrar un mensaje de confirmación.

### Historia de usuario 2: Cambiar estado de tareas

Como usuario, quiero cambiar el estado de una tarea para conocer su progreso.

Criterios de aceptación:
- Debe permitir seleccionar pendiente.
- Debe permitir seleccionar en proceso.
- Debe permitir seleccionar terminada.
- El cambio debe reflejarse en el listado de tareas.

### Historia de usuario 3: Consultar tareas

Como usuario, quiero consultar las tareas registradas para conocer mis actividades.

Criterios de aceptación:
- El sistema debe mostrar las tareas registradas.
- Debe mostrar el nombre y la descripción.
- Debe mostrar el estado y la prioridad.

### Historia de usuario 4: Editar tareas

Como usuario, quiero editar las tareas para actualizar su información.

Criterios de aceptación:
- El sistema debe permitir seleccionar una tarea.
- Debe permitir modificar su información.
- Los cambios deben guardarse.
- La información actualizada debe mostrarse en el listado.

### Historia de usuario 5: Eliminar tareas

Como usuario, quiero eliminar tareas que ya no sean necesarias.

Criterios de aceptación:
- El sistema debe permitir seleccionar una tarea.
- Debe permitir eliminar la tarea.
- La tarea eliminada no debe aparecer en el listado.

### Historia de usuario 6: Asignar prioridad

Como usuario, quiero asignar una prioridad a las tareas para organizar mis actividades.

Criterios de aceptación:
- Debe permitir seleccionar prioridad alta.
- Debe permitir seleccionar prioridad media.
- Debe permitir seleccionar prioridad baja.
- La prioridad debe guardarse y mostrarse en el listado.
